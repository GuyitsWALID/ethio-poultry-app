# Connect approved feed templates to daily work (findings 15–16)

Linked to `simplify-farm-operations` and `complete-operational-planning`.

Today resolves the active approved template for the selected flock's actual age/date, including arrival age. The daily target uses the established trustworthy opening-population resolver, never today's current count as historical evidence. Missing template/range/population/type remains explicit and unavailable. The whole-day target, session allocation and remaining allocation are bilingual; arbitrary session counts and all stock/save safeguards remain unchanged. Generated schedules are no longer Today target authority, so the 90-day generated horizon cannot erase the recommendation.

For Today-enabled organizations, approved templates generate source-linked one-time Scheduler weight rules for applicable even-week rows using actual flock placement/arrival age. Rolling generation creates occurrences and existing Today/Finish day treats them as required work. Template-owned rules require an approved template change. Future promises are revised with audit provenance; today's promised work is preserved. Disabled organizations retain their existing legacy generation, not simultaneous duplicate requirements.

Existing legacy weight tasks are not auto-matched or marked complete. Scheduler offers a CEO-only explicit rescheduling decision with exact legacy identity/revision, date, reason and confirmation. It creates a named-flock Scheduler rule, preserves immutable original evidence and audit history, and is retry-safe. Archived/changed/completed legacy sources are blocked. No records or historical dates are rewritten.
