# Operational Analytics design comparison

## Direction

Farm performance remains the authorized, bilingual reporting workspace. Reuse the older CEO Operational Analytics page's visual reasoning, not its separate read path or English-only controls.

The older page's strengths are aligned operating signals, visible target comparisons, contextual explanations and a clear attention hierarchy. The previous Farm performance layout put each chart in an isolated, equally weighted card and separated filters from the page's purpose.

## Presentation changes

- A single forest control-room header holds the title, refresh and date/location filters.
- Overview puts results first, followed by synchronized production-rate, feed-per-bird and loss tracks beside supported concerns.
- Shared operating dates align cursors; separate scales preserve incompatible units. Missing observations remain gaps, and failed sources do not become zero-valued tracks.
- A flock comparison board shows recorded production or latest weight beside existing age targets, with coverage, measurement dates and exact evidence links. Rails use independent scales, not a fabricated cross-flock score.
- Existing topic charts, supporting tables, saved reports, URL filters and permission checks remain intact.
- Palette: forest `#1d2a1f`, leaf `#358e50`, straw `#a16207`, loss ember `#c9472d`, evidence blue `#2b6cb0`, paper `#f8f6f2`. Reuse existing display and body fonts; tabular numerals carry the data.
- Signature: the operating-rhythm tracks share dates and cursors, not units. A coordinated pattern is an investigation clue, never a diagnosis.
- All new explanatory copy is present in English and Amharic. No animation is introduced; charts retain disabled animation and table alternatives.

No schema, source-read, aggregation, authorization or saved-report changes are part of this presentation update. It does not add database calls or change frozen snapshot contents.

## Verification

Focused regressions cover aligned date gaps, genuine zeroes, failed-source exclusion, retained units, missing targets and unclipped over-target rails. Visual acceptance on signed-in tablet/desktop remains a manual release check.
